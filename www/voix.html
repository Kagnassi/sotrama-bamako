Enregistre ta propre voix pour l'apprenti, les passagers et les policiers. Tes enregistrements sont utilisés tout de suite dans le jeu, sur cet appareil.

Pour que tout le monde entende ta voix dans l'application, clique sur « Tout télécharger », dézippe le fichier dans le dossier www/voix/ du projet, puis fais un git push.
