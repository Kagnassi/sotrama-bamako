Comment jouer
  • Arrête-toi dans un cercle blanc : les passagers qui attendent montent.
  • Les cercles dorés sont leurs quartiers : 250 F la course, 300 F s'ils traversent le fleuve, 50 F de plus pour les longs trajets.
  • Les cercles rouges sont les stations : le carburant coûte 800 F le litre, payé avec la recette du jour.
  • Évite les motos Djakarta, les taxis et les autres Sotrama : un accident coûte 500 à 1 000 F.
